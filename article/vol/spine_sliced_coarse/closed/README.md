# `spine_sliced_coarse/closed/`

Coarse-resolution plasma-membrane surface, capped into a closed (boundary-
free) mesh. `fixing.py`/`fixingNEW.py` reproduce the `*_fixed.vol` files
from the raw segmented mesh. Used by the stationarity supplementary test.
See [`closed/filled/`](filled/) for the volumetric (tetrahedral) version of
this same mesh, and [`../../README.md`](../../README.md) for the full
pipeline explanation.
