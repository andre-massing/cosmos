# `spine_sliced_coarse/closed/filled/`

Coarse-resolution spine, closed membrane filled in with a tetrahedral bulk
mesh (a true volumetric mesh of the cytoplasm). `fixing.py`/`fixingNEW.py`
reproduce the `*_fixed.vol` files. See
[`../../../README.md`](../../../README.md) for the full pipeline
explanation, including what these `fixing*.py` scripts do.
