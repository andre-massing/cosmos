# `spine_sliced_coarse/open/`

Coarse-resolution plasma-membrane surface, with the open cut boundary as
sliced from the segmentation. `fixing.py`/`fixingNEW.py` reproduce the
`*_fixed.vol` files from the raw segmented mesh. Used by the
external-force and stationarity supplementary tests. See
[`../../README.md`](../../README.md) for the full pipeline explanation.
