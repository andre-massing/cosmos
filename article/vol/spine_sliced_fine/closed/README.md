# `spine_sliced_fine/closed/`

Fine-resolution plasma-membrane surface, capped into a closed (boundary-
free) mesh. `fixing.py` reproduces the `*_fixed.vol` file from the raw
segmented mesh. See [`closed/filled/`](filled/) for the volumetric
(tetrahedral) version of this same mesh, and
[`../../README.md`](../../README.md) for the full pipeline explanation.
