# `spine_sliced_intermed/closed/`

Intermediate-resolution plasma-membrane surface, capped into a closed
(boundary-free) mesh. `fixing.py` reproduces the `*_fixed.vol` file from
the raw segmented mesh. See [`closed/filled/`](filled/) for the volumetric
(tetrahedral) version of this same mesh -- the one actually loaded by
[`../../../Application_3_realistic_spine.py`](../../../Application_3_realistic_spine.py)
-- and [`../../README.md`](../../README.md) for the full pipeline
explanation.
