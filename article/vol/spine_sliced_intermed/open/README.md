# `spine_sliced_intermed/open/`

Intermediate-resolution plasma-membrane surface, with the open cut boundary
as sliced from the segmentation. `fixing.py` reproduces the `*_fixed.vol`
file from the raw segmented mesh; also used as the boundary-tag reference
by `closed/filled/fixing_tetr.py`. See
[`../../README.md`](../../README.md) for the full pipeline explanation.
